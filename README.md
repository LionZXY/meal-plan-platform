# Meal plan platform

Статическая платформа для просмотра рационов по людям и датам. Приложение загружает JSON во время открытия страницы; всё меню, КБЖУ продуктов и изображения лежат отдельно в `content/`.

[Открыть платформу](https://kulikov.uk/meal-plan-platform/) · [Репозиторий](https://github.com/LionZXY/meal-plan-platform)

Старая ссылка `seven-days-meal-plan-october.nikita689636.chatgpt.site` направляет на эту платформу. Авторитетный источник для будущих изменений — этот GitHub-репозиторий.

- Автоматически выбирает сегодняшний день в часовой зоне каталога.
- Позволяет выбирать человека и сохраняет его ID в браузере.
- Поддерживает несколько недель и пустой профиль до добавления настоящего меню.
- Считает КБЖУ по отображаемым порциям и показывает исходные названия продуктов.
- Проверяет данные и запускает тесты перед автоматической публикацией на GitHub Pages.

Сейчас в данных: текущий рацион Никиты на 10–16 октября; профиль Насти готов для добавления меню. Независимые тестовые рационы обоих пользователей находятся только в `tests/fixtures.js`.

## Запуск

Node.js 24 или новее:

```sh
npm ci
npm test
npm run validate
npm run build
npm run preview
```

Предпросмотр: `http://127.0.0.1:18763/`. Проверка пути GitHub Pages: `npm run preview -- --base /meal-plan-platform/`.

## Добавление рациона

Читайте [формат данных](docs/content-format.md) или используйте проектный скилл [add-meal-plan](.agents/skills/add-meal-plan/SKILL.md). Добавьте `plan.json` и изображения, затем запись в `content/catalog.json`; менять код не требуется. Дата и выбор профиля проверяются независимыми тестовыми данными, поэтому замена реальных меню не требует изменения тестов.

## Публикация

`.github/workflows/pages.yml` запускает тесты, проверяет содержимое и собирает сайт на push в `main`. При успехе публикует на GitHub Pages. PR проходят те же проверки без публикации. В настройках репозитория GitHub Pages должен быть включён источник GitHub Actions (`build_type: workflow`).

Браузер использует localStorage только для выбора человека. Аккаунты и пароли не нужны. Модуль приложения и пакет контента получают разные версии путей для корректного обновления кэша. Сборка не публикует документацию, исходные тесты или node_modules.

## Структура

| Путь | Назначение |
|---|---|
| `content/` | Каталог, реальные рационы и изображения |
| `src/model.js` | Даты, КБЖУ, проверка формата |
| `src/app.js` | Загрузка и выбор профиля/дня |
| `src/render.js` | Безопасное отображение содержимого |
| `public/` | Оболочка HTML и стили |
| `scripts/` | Проверка, сборка, предпросмотр |
| `tests/` | Unit, DOM, данные и сборка |
| `.agents/skills/` | Инструкция для будущего добавления рационов |
| `dist/` | Автоматически созданный результат сборки |
